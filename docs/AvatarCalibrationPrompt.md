# 8-second avatar calibration prompt (Gemini / user)

Use this exact script so Side B labels are known by time.

## Prompt (paste into Gemini / video generator)

```text
Create a single continuous frontal close-up video of one adult face, 8.0 seconds,
24 or 30 fps, neutral lighting, eyes visible, no sunglasses, head mostly still,
looking at camera. No cuts. Speak clearly in English.

Timeline (follow exactly):
0.0–1.0s REST: neutral closed mouth, relaxed face, silence.
1.0–2.0s SMILE: closed-lip smile, corners wide, no big jaw drop.
2.0–3.0s OPEN: say “ah” with jaw clearly open so teeth show.
3.0–4.0s SAY_HI: clearly say the word “hi” once.
4.0–5.0s SURPRISE: raise eyebrows, widen eyes, soft “oh” face.
5.0–6.0s ANGRY: frown / angry expression, brows down.
6.0–7.5s TALK: say exactly: “Hello there. How are you today?”
7.5–8.0s REST: return to neutral closed mouth.

Output: one MP4, face filling most of the frame, stable crop.
```

## Save as

`output/worlds/<avatar>/calibration_take.mp4`  
plus `calibration_script.json` (generated by `aiface.tickfeed.calibration`).

## Then

```powershell
python scripts/prepare_tickfeed.py --world-dir output/worlds/avatar --video path\to\calibration_take.mp4
python scripts/train_tickfeed_ml.py --world-dir output/worlds/avatar
```
